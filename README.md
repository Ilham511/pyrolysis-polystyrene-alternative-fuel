# Pyrolysis of Polystyrene Plastic Waste into Alternative Fuel

## Project Overview

This project investigates the conversion of Polystyrene (PS) plastic waste into liquid alternative fuel through a pyrolysis process using the PITARA (Multi-Stage Tubular Reactor).

The experiment was conducted at three pyrolysis temperatures: **250°C, 300°C, and 350°C**. The resulting pyrolysis oil was subsequently treated using **bentonite** as an adsorbent to improve its physical and physicochemical characteristics.

The project evaluates the resulting pyrolysis oil based on **oil volume, density, kinematic viscosity, and flash point**.

## Experimental Setup

| Parameter             | Description                        |
| --------------------- | ---------------------------------- |
| Feedstock             | Polystyrene (PS) plastic waste     |
| Feedstock mass        | 4.5 kg                             |
| Particle size         | 10 × 10 mm                         |
| Reactor               | PITARA Multi-Stage Tubular Reactor |
| Reactor diameter      | 28 cm                              |
| Reactor height        | 30 cm                              |
| Pyrolysis temperature | 250°C, 300°C, 350°C                |
| Process condition     | Anaerobic                          |
| Adsorbent             | Bentonite                          |
| Pyrolysis duration    | 180 minutes                        |

The Polystyrene waste was washed, dried, and reduced to a particle size of 10 × 10 mm before being introduced into the PITARA reactor.

The resulting vapor was directed to a condenser to produce liquid pyrolysis oil. The oil was then treated using bentonite before physicochemical characterization.

## Process

```text
Polystyrene Waste
        ↓
Washing & Drying
        ↓
Size Reduction
        ↓
PITARA Pyrolysis
        ↓
Condensation
        ↓
Pyrolysis Oil
        ↓
Bentonite Treatment
        ↓
Physicochemical Testing
```
